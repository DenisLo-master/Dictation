# Changelog

## 0.1.13 - 2026-05-20

Initial public-ready build.

- Status-bar push-to-talk dictation for macOS.
- OpenAI transcription model selection and token validation.
- Hotkey recorder with `Fn / Globe` default and fallback keys.
- Voice-reactive square-cell equalizer and transcription spinner.
- Clipboard paste insertion with clipboard restoration.
- Launch-at-login option.
- Local logs with the last 10 entries.
- Idempotent package installer and DMG distribution.
- Current builds available in `dist/`.
